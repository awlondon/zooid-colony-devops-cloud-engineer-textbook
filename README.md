# Write a full textbook for a DevOps/cloud engineer undergraduate senior level student preparing for...

**Purpose:** Write a full textbook for a DevOps/cloud engineer undergraduate senior level student preparing for graduate level and professional software work.

This repository holds a software project produced by a PDC Zooid Colony. It is laid out so it can be pushed to GitHub as it is:

```
git init && git add . && git commit -m "Initial commit"
```

## Layout

- `src/`
- `tests/`
- `docs/`
- `PROJECT.json` - the definition of done the colony works against (editable)
- `STATUS.md` - which requirements hold right now, and who is working on what
